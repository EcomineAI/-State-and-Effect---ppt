# State and Effect — React slide deck

```bash
npm install
npm run dev      # develop
npm run build    # static build in dist/
```

Keys: → ↓ Space Enter / ← ↑ Backspace, Home / End, F = fullscreen. Swipe on touch. Slide number is kept in the URL hash.
Content lives in `src/slides.jsx`; layouts in `src/components/layouts.jsx`; window chrome in `src/components/Window.jsx`.
